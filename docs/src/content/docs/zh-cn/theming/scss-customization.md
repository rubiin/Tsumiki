| 变量 | 默认值 | 描述 |
|---|---|---|
| `$bar-background` | 主题色 | 状态栏背景 |
| `$bar-border-radius` | `16px` | 圆角半径 |
| `$bar-padding` | `4px 12px` | 内边距 |

| 类名 | 效果 |
|---|---|
| `compact` | 减少间距 |
| `bordered` | 添加边框 |
| `pill` | 药丸形容器 |
