---
title: Dicas de Tematização
description: Conselhos práticos de tematização para Tsumiki
---

## Mantenha o Contraste Alto

O texto deve ser legível em todas as superfícies.

## Teste Superfícies Comuns

Barra principal, configurações rápidas, notificações, lançador e dock.

## Use Acentos Semânticos

Reserve cores fortes para estados importantes.

## Fluxo de Trabalho Matugen

1. `matugen.enabled = true` no `config.toml`
2. Aponte `wallpaper` para sua imagem
3. Reinicie o Tsumiki
4. Recompile se necessário: `./init.sh -recompile`
