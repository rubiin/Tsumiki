---
title: Criação de Temas
description: Como criar temas para Tsumiki
---

```bash
touch themes/meu-tema.toml
```

```toml
[dark.background]
main = "#121212"
alt = "#1a1a1a"

[dark.text]
main = "#e0e0e0"
secondary = "#c5c5c5"

[dark.accent]
blue = "#00d0ff"
green = "#00ff00"

[light.background]
main = "#ededed"

[light.text]
main = "#1f1f1f"
```

```toml
[styling]
theme_name = "meu-tema"
```
