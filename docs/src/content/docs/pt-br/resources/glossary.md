---
title: Glossário
description: Termos-chave usados na documentação do Tsumiki
---

## Widget

Elemento de UI pequeno e autossuficiente no painel.

## Módulo

Superfície de UI maior além da barra, como dock, notificações ou OSD.

## Layout

Define onde os widgets aparecem na barra.

## Tema

Conjunto de variáveis de cor em `themes/*.toml`.

## Matugen

Ferramenta que gera paletas Material You a partir de uma imagem.

## Fabric

Sistema de widgets no qual o Tsumiki é construído.
