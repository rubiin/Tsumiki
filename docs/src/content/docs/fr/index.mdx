## Qu'est-ce que Tsumiki ?

Tsumiki (anciennement Hydepanel) est une barre d'état modulaire pour le compositeur Wayland Hyprland.
Il est construit sur le système de widgets Fabric et conçu autour de petits widgets composites.

## Fonctionnalités
