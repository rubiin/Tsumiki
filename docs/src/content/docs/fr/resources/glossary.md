---
title: Glossaire
description: Termes clés utilisés dans la documentation Tsumiki
---

## Widget

Élément d'interface petit et autonome sur le panneau (ex. horloge, batterie, volume).

## Module

Surface d'interface plus grande au-delà de la barre, comme le dock, les notifications, l'aperçu ou l'OSD.

## Disposition (Layout)

Définit où les widgets apparaissent sur la barre via `left_section`, `middle_section`, `right_section`.

## Thème

Ensemble de variables de couleur définies dans `themes/*.toml` et utilisées par SCSS.

## Matugen

Outil qui génère des palettes de couleurs Material You à partir d'une image de fond d'écran.

## Fabric

Le système de widgets sur lequel Tsumiki est construit.

## Groupe Pliable

Groupe de widgets cachés derrière un bouton, défini avec `[[collapsible_groups]]`.

## Groupe de Widgets

Collection nommée de widgets avec espacement et classes de style partagés, définie avec `[[widget_groups]]`.
