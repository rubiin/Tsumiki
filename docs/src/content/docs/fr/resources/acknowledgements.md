## Inspirations

Tsumiki a été façonné par des projets qui ont fait évoluer les barres modulaires dans l'écosystème Wayland :

- **Waybar** : inspiration majeure pour les concepts de panneau.
- **HyprPanel** : inspiration pour le comportement dynamique du panneau.
