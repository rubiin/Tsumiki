## ¿Qué es Tsumiki?

Tsumiki (anteriormente Hydepanel) es una barra de estado modular para el compositor Wayland Hyprland.
Está construido sobre el sistema de widgets Fabric y diseñado alrededor de widgets pequeños y componibles.

## Características
