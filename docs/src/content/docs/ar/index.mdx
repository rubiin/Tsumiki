## ما هو تسوميكي؟

تسوميكي (المعروف سابقاً بـ Hydepanel) هو شريط حالة معياري لمدير النوافذ هيبرلاند.
تم بناؤه على نظام Fabric للواجهات وصُمم حول أدوات واجهة صغيرة وقابلة للتركيب.
