## ما هو تسوميكي؟

تسوميكي (المعروف سابقاً بـ Hydepanel) هو شريط حالة معياري لمدير النوافذ [Hyprland](https://hyprland.org). مبني على نظام [Fabric](https://github.com/Fabric-Development/fabric) للواجهات، ويوفر بنية مرنة لبناء لوحات سطح مكتب مخصصة من خلال أدوات واجهة قابلة للتركيب.

الاسم **تسوميكي** (積み木) يعني "مكعبات البناء" باليابانية — مما يعكس التصميم المعياري القابل للتكديس للمشروع.

## المتطلبات الأساسية

قبل تثبيت تسوميكي، تأكد من أن نظامك يلبي هذه المتطلبات:

| المتطلب                                          | ملاحظات                                                     |
| ------------------------------------------------ | ----------------------------------------------------------- |
| [Hyprland](https://hyprland.org)                 | يلزم تثبيت عامل لـ Hyprland                                 |
| [JetBrains Nerd Font](https://www.nerdfonts.com) | مطلوب لعرض الأيقونات والرموز                                |
| **Python 3.12+**                                 | يتطلب تسوميكي Python 3.12                                   |
| **uv**                                           | مدير حزم بايثون المستخدم لتثبيت التبعيات (`uv sync`)        |
| **Arch Linux** (موصى به)                         | حزم محسنة لـ Arch؛ التوزيعات الأخرى قد تحتاج إعداداً يدوياً |
| **NetworkManager**                               | مطلوب لأدوات وخدمات الشبكة                                  |
| **PipeWire**                                     | مطلوب لأدوات الصوت وOSD                                     |

## المفاهيم الرئيسية

### الأدوات (Widgets)

الأدوات هي اللبنات الأساسية التي تظهر في الشريط. هناك أكثر من 45 أداة مدمجة تغطي:

- **معلومات النظام** — المعالج، الذاكرة، بطاقة الرسوميات، التخزين، استخدام الشبكة
- **التحكم في الأجهزة** — الصوت، السطوع، الميكروفون، البطارية
- **إدارة سطح المكتب** — مساحات العمل، عنوان النافذة، شريط المهام
- **الأدوات المساعدة** — لقطة الشاشة، OCR، الحافظة، تسجيل الشاشة
- **الإنتاجية** — مؤقت بومودورو، لوحة كانبان، ساعة إيقاف، منتقي الرموز التعبيرية
- **التكامل** — الطقس، التحكم في الوسائط، مرافق Git، مبدل DNS

يتم تكوين كل أداة تحت `[widgets.<الاسم>]` في `config.toml`. راجع [مرجع الأدوات](/ar/features/widgets) للقائمة الكاملة.

### الوحدات (Modules)

الوحدات هي أسطح واجهة أكبر تتجاوز الشريط — وهي نوافذ أو تراكبات مستقلة:

- **الشريط** — اللوحة الرئيسية نفسها
- **نظام الإشعارات** — عرض إشعارات سطح المكتب
- **الإرساء (Dock)** — إرساء التطبيقات مع الإخفاء الذكي
- **النظرة العامة** — عرض مساحات العمل بملء الشاشة
- **مشغل التطبيقات** — بحث عن التطبيقات عبر لوحة المفاتيح
- **OSD** — شاشات عرض للصوت والسطوع وغيرها
- **ساعة سطح المكتب** — تراكب ساعة زخرفي
- **اقتباسات سطح المكتب** — عرض اقتباسات ملهمة

يتم تكوين الوحدات تحت `[modules.<الاسم>]` في `config.toml`. راجع [مرجع الوحدات](/ar/features/modules) للتفاصيل.

### التخطيط

يتم التحكم في موضع الأدوات في الشريط بواسطة قسم `[layout]` من `config.toml`:

```toml
[layout]
left_section = ["workspaces", "window_title"]
middle_section = ["date_time"]
right_section = ["volume", "battery", "system_tray"]
```

يمكن أيضاً تجميع الأدوات أو وضعها في مجموعات قابلة للطي. راجع [الإعدادات](/ar/configuring/config) للتفاصيل.

### الخدمات

الخدمات هي عمليات خلفية تزود الأدوات بالبيانات — تراقب مستويات البطارية، حالة الشبكة، مشغلات الوسائط، الطقس والمزيد. تتصل الأدوات بالخدمات عبر إشارات GTK، مما يحافظ على كفاءة التحديثات.

## البنية

تتبع بنية تسوميكي تصميماً متعدد الطبقات:

```text
┌──────────────────────────────────────────────┐
│                  main.py                       │
│   ┌──────────┐  ┌──────────┐  ┌───────────┐  │
│   │ Config    │  │ CSS      │  │ Module     │  │
│   │ Loader   │  │ Compiler │  │ Init       │  │
│   └──────────┘  └──────────┘  └───────────┘  │
└─────────────────────┬────────────────────────┘
                      │
        ┌─────────────┼─────────────┐
        ▼             ▼             ▼
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ Services │  │ Widgets  │  │ Modules  │
  │ (DBus,   │──▶│ (Panel   │──▶│ (Overlay │
  │ polling) │  │ buttons) │  │ windows) │
  └──────────┘  └──────────┘  └──────────┘
```

- **الخدمات** تعمل في الخلفية وتصدر إشارات GTK عند تغيرات الحالة
- **الأدوات** هي أزرار لوحة تشترك في إشارات الخدمات
- **الوحدات** هي نوافذ GTK مستقلة للتراكبات والنوافذ المنبثقة

راجع صفحة [البنية](/ar/resources/architecture) لنظرة أعمق.

## المسار الموصى به

1. **[تثبيت تسوميكي](/ar/getting-started/installation)** — استنساخ، تثبيت الاعتماديات، إعداد البيئة.
2. **اتبع [الخطوات الأولى](/ar/getting-started/first-steps)** — ابدأ الشريط، هيئ التخطيط، طبق قواعد ما بعد التثبيت.
3. **تعلم [الإعدادات](/ar/configuring/config)** — افهم هيكل إعدادات TOML والخيارات المتاحة.
4. **اختر ثيمك** — ابدأ بثيم مدمج أو اصنع بنفسك مع [صنع الثيمات](/ar/theming/making-themes).
5. **استكشف** — أضف الأدوات، فعّل الوحدات، خصص السلوك.
