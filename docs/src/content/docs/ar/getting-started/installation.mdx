## المتطلبات الأساسية

تأكد من تثبيت هذه المتطلبات قبل المتابعة:

| المتطلب                                          | أمر التثبيت (Arch Linux)                 | ملاحظات                   |
| ------------------------------------------------ | ---------------------------------------- | ------------------------- |
| [Hyprland](https://hyprland.org)                 | `sudo pacman -S hyprland`                | يجب تشغيل Hyprland        |
| [JetBrains Nerd Font](https://www.nerdfonts.com) | `sudo pacman -S ttf-jetbrains-mono-nerd` | مطلوب لعرض الأيقونات      |
| **Python 3.12+**                                 | `sudo pacman -S python`                  | تحقق: `python --version`  |
| **Git**                                          | `sudo pacman -S git`                     | مطلوب للاستنساخ           |
| **NetworkManager**                               | `sudo pacman -S networkmanager`          | مطلوب بواسطة أدوات الشبكة |
| **PipeWire**                                     | `sudo pacman -S pipewire pipewire-pulse` | مطلوب بواسطة أدوات الصوت  |

::::caution
تحتاج إلى **إعداد Hyprland عامل** قبل تثبيت تسوميكي. إذا كنت جديداً على Hyprland، اتبع [Wiki Hyprland](https://wiki.hyprland.org/Getting-Started/) أولاً.
::::

## خيارات التثبيت

اختر واحدة من الطرق الثلاث التالية.

### الخيار 1: سكريبت التمهيد (الأسرع)

```sh
curl -fsSL https://raw.githubusercontent.com/rubiin/tsumiki/master/install.sh | bash
```

هذا السكريبت يستنسخ أو يحدّث `~/.config/tsumiki`، ثم يشغّل الإعداد الكامل.

لتثبيت **وتشغيل** فوراً:

```sh
curl -fsSL https://raw.githubusercontent.com/rubiin/tsumiki/master/install.sh | bash -s -- --start
```

### الخيار 2: الإعداد الآلي في استنساخ موجود

إذا سبق أن استنسخت المستودع يدوياً، شغّل سكريبت الإعداد:

```sh
./tsumiki.sh -setup
./tsumiki.sh -start
```

العلامة `-setup` تثبت حزم النظام المطلوبة وتضبط البيئة الافتراضية لـ Python.

### الخيار 3: إعداد التبعيات يدوياً

تفضل السيطرة الكاملة على الحزم؟ ثبت التبعيات بنفسك ثم ابدأ:

```sh
# تثبيت حزم النظام
sudo pacman -S --noconfirm --needed \
  pipewire playerctl dart-sass power-profiles-daemon networkmanager \
  brightnessctl pkgconf wf-recorder kitty python pacman-contrib \
  gtk3 cairo gtk-layer-shell libgirepository noto-fonts-emoji \
  gobject-introspection gobject-introspection-runtime uv \
  python-gobject python-psutil python-cairo python-loguru libnotify \
  cliphist libqalculate python-httpx satty nvtop

# تثبيت حزم AUR (باستخدام yay كمثال)
yay -S --needed \
  python-fabric-git gnome-bluetooth-3.0 python-rlottie-python \
  python-pytomlpp slurp imagemagick tesseract tesseract-data-eng \
  ttf-jetbrains-mono-nerd grimblast-git python-ijson

# تثبيت تبعيات Python
uv sync

# بدء
./tsumiki.sh -start
```

إذا كنت لا تستخدم `yay`، ثبّت حزم AUR بمساعد AUR المفضل لديك.

## إعداد التشغيل التلقائي

أضف هذا السطر إلى `~/.config/hypr/hyprland.conf` لتشغيل تسوميكي تلقائياً عند بدء Hyprland:

```sh
exec-once = sleep 5; ~/.config/tsumiki/tsumiki.sh -start
```

`sleep 5` يضمن تهيئة Hyprland بالكامل قبل تشغيل تسوميكي. اضبط المسار إذا استنسخت في موقع مختلف.

:::tip
يمكنك إنشاء alias في الشيل للراحة:

```sh
alias tsumiki='~/.config/tsumiki/tsumiki.sh -start'
```

:::

## التحقق من التثبيت

1. شغّل `./tsumiki.sh -start` من مجلد المشروع.
2. يجب أن يظهر شريط تسوميكي في أعلى شاشتك.
3. إذا رأيت رسائل خطأ، تحقق من:
   - تثبيت جميع حزم النظام (`./tsumiki.sh -setup` يعيد تشغيل هذا الفحص)
   - تثبيت تبعيات Python (`uv sync`)
   - أنك تعمل تحت Hyprland (وليس مشغّل آخر أو X11)

إذا لم يظهر الشريط، راجع [استكشاف الأخطاء وإصلاحها](/ar/help/troubleshooting).
