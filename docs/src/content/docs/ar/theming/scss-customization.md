| المتغير | الافتراضي | الوصف |
|---|---|---|
| `$bar-background` | لون الثيم | خلفية الشريط |
| `$bar-border-radius` | `16px` | زوايا مدورة |
| `$bar-padding` | `4px 12px` | حشوة داخلية |

| الفئة | التأثير |
|---|---|
| `compact` | تقليل المسافات |
| `bordered` | إضافة حد |
| `pill` | شكل حبة الدواء |
