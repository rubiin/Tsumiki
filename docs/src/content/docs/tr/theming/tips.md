## Yüksek Kontrastı Koruyun

Metin tüm yüzeylerde okunabilir kalmalıdır.

## Yaygın Yüzeyleri Test Edin

Ana çubuk, hızlı ayarlar, bildirimler, başlatıcı, dock.

## Anlamsal Vurgular Kullanın

Güçlü renkleri önemli durumlar için saklayın.

## Matugen İş Akışı

1. `config.toml` içinde `matugen.enabled = true` ayarlayın
2. `wallpaper`'ı görselinize yöneltin
3. Tsumiki'yi yeniden başlatın
4. Gerekirse yeniden derleyin: `./init.sh -recompile`
