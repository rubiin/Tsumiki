| Değişken             | Varsayılan | Açıklama          |
| -------------------- | ---------- | ----------------- |
| `$bar-background`    | tema rengi | Çubuk arka planı  |
| `$bar-border-radius` | `16px`     | Köşe yuvarlaklığı |
| `$bar-padding`       | `4px 12px` | İç dolgu          |

| Sınıf      | Etki              |
| ---------- | ----------------- |
| `compact`  | Azaltılmış boşluk |
| `bordered` | Kenarlık ekler    |
| `pill`     | Hap şeklinde kap  |
