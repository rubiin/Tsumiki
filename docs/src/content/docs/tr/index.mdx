## Tsumiki Nedir?

Tsumiki (eski adıyla Hydepanel), Hyprland Wayland birleştiricisi için modüler bir durum çubuğudur.
Fabric widget sistemi üzerine inşa edilmiş ve küçük, birleştirilebilir widget'lar etrafında tasarlanmıştır.
