## Widget

Paneldeki küçük, bağımsız UI öğesi.

## Modül

Çubuğun ötesinde daha büyük UI yüzeyi.

## Düzen (Layout)

Widget'ların çubukta nerede görüneceğini belirler.

## Tema

`themes/*.toml` içindeki renk değişkenleri kümesi.

## Matugen

Görsellerden Material You paletleri oluşturan araç.

## Fabric

Tsumiki'nin üzerine inşa edildiği widget sistemi.
