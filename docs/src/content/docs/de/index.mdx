## Was ist Tsumiki?

Tsumiki (ehemals Hydepanel) ist eine modulare Statusleiste für den Hyprland Wayland-Compositor.
Es basiert auf dem Fabric-Widget-System und ist auf kleine, zusammensetzbare Widgets ausgelegt.

## Funktionen
