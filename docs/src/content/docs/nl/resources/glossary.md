description: Belangrijke termen in de Tsumiki-documentatie
---

## Widget

Klein, zelfstandig UI-element op het paneel.

## Module

Groter UI-oppervlak buiten de balk.

## Layout

Bepaalt waar widgets op de balk verschijnen.

## Thema

Verzameling kleurvariabelen in `themes/*.toml`.

## Matugen

Tool die Material You-paletten genereert uit afbeeldingen.

## Fabric

Het widgetsysteem waarop Tsumiki is gebouwd.
