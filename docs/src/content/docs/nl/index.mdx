## Wat is Tsumiki?

Tsumiki (voorheen Hydepanel) is een modulaire statusbalk voor de Hyprland Wayland-compositor.
Het is gebouwd op het Fabric-widgetsysteem en ontworpen rond kleine, samengestelde widgets.
